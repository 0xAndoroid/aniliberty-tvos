# AniLiberty
iOS клиент для сайта [AniLiberty](https://aniliberty.top)

Этот репозиторий — форк iOS-приложения [anilibria/anilibria-ios](https://github.com/anilibria/anilibria-ios), которое распространяется под лицензией GPL-3.0. Исходный код изменён в ноябре 2026 года: добавлено приложение для Apple TV (tvOS), оно описано в разделе [tvOS](#tvos). К официальным релизам AniLibria/AniLiberty форк не относится.

## Информация
|Версия приложения |iOS/iPad.           |macOS                 |
|------------------|--------------------|----------------------|
| 1.0.1..<1.1.4    | iOS 11.2 и новее   | macOS 10.15 и новее  | 
| 1.2.0...         | iOS 13.0 и новее   | macOS 11 и новее     |
| сборка в Xcode 27 | iOS 15.0 и новее  | macOS 12 и новее     |


## Установка
Приложение вы можете собрать самостоятельно, либо скачать посдедний релиз [отсюда](https://github.com/anilibria/anilibria-ios/releases). По этой ссылке лежат сборки исходного iOS-приложения; готовых сборок для tvOS этот репозиторий не публикует.

Установить ipa на ваш девайс вы можете c помощью AltStore
  - Офф сайт: [altstore.io](https://altstore.io/)

Другие способы можете поискать в интернете.

## tvOS
Приложение для Apple TV (tvOS 17.0 и новее) собирается из того же проекта: цель `AniLibertyTV`, код экранов лежит в папке `AniLibertyTV`. Сетевой слой, модели и логика плеера общие с iOS.

Экраны написаны на SwiftUI. Проект собирается в Xcode 27.

### Что работает
Проверено 15 ноября 2026 года в симуляторе tvOS 27.0 без входа в аккаунт:

- вкладки «Главная», «Каталог», «Избранное», «Профиль» и «Поиск»;
- последние релизы и ряд «Продолжить просмотр»;
- каталог с фильтром по жанрам и выбором сортировки;
- поиск;
- страница релиза с описанием и списком серий;
- системный плеер с меню качества: 1080p, 720p или 480p;
- позиция просмотра каждой серии сохраняется на устройстве, и серию можно продолжить с неё.

Интерфейс на русском языке. Рекламы и аналитики в приложении для tvOS нет; SDK AppMetrica и KSCrash, которые использует iOS-приложение, к цели `AniLibertyTV` не подключены.

### Что не проверено и не реализовано
Реализовано, но с настоящим аккаунтом не проверялось:

- вход по коду, который показан на экране;
- вход по логину и паролю;
- избранное;
- синхронизация позиций просмотра для аккаунта.

Не реализовано:

- автоматический переход к следующей серии;
- пропуск опенингов;
- коллекции;
- вход через VK, Google, Patreon и Discord;
- регистрация;
- торренты.

На tvOS с 17 по 26 приложение не проверялось.

### Сборка
Сборка для симулятора. Сертификат разработчика не нужен: такую сборку Xcode подписывает локально.

```sh
xcodebuild -project Anilibria.xcodeproj -scheme AniLibertyTV -destination 'generic/platform=tvOS Simulator' build
```

Так же собирается iOS-приложение:

```sh
xcodebuild -project Anilibria.xcodeproj -scheme AniLiberty -destination 'generic/platform=iOS Simulator' build
```

Не отключайте подпись (`CODE_SIGNING_ALLOWED=NO`) в сборке, которую будете запускать: без подписи приложение не получает доступа к связке ключей, где хранится токен входа.

Чтобы установить приложение на Apple TV, откройте проект в Xcode, выберите схему `AniLibertyTV` и запустите её на приставке. Проверить, что приложение компилируется для приставки, можно без сертификата:

```sh
xcodebuild -project Anilibria.xcodeproj -scheme AniLibertyTV -destination 'generic/platform=tvOS' CODE_SIGNING_ALLOWED=NO build
```
